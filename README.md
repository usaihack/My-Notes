## Executive Overview

This repository documents my structured progression into **Ethical Hacking, Network Penetration Testing, and Security Engineering**. Designed as a comprehensive technical portfolio, every module is built around first-hand lab execution, command-line analysis, packet capture verification, and practical assignments.

### Core Portfolio Highlights:
- **Zero Placeholder Material**: All notes are original records of hands-on practice on Kali Linux, virtual lab networks, and CTF challenges.
- **Dual Attacker / Defender Lens**: Every protocol and system feature is analyzed from both an offensive abuse angle and a defensive mitigation strategy.
- **Evidence-Based Documentation**: Notes include actual terminal outputs, payload structures, system state snapshots, and configuration files.
- **Automated CI/CD Portfolio Engine**: Content indexes and progress trackers are automatically generated and updated via custom CI/CD pipelines upon every commit.

## Automated Portfolio Pipeline

This repository features an automated documentation engine ([`update-readme.yml`](.github/workflows/update-readme.yml)) powered by Python ([`generate_readme.py`](scripts/generate_readme.py)):

1. **Automated Content Indexing**: When a new study note (`Day-XX, Topic.md`) is pushed, GitHub Actions parses the technical contents, extracts key security concepts using automated natural language indexing, and caches summary metadata (`.summary_cache.json`).
2. **Dynamic Curriculum State**: Module completion states (`✅ Complete`, `🔄 In Progress`, `📋 Planned`) update dynamically based on active month progress and repository commit activity.
3. **Automated Directory Tree**: System directory architecture is dynamically updated to reflect newly added modules and laboratory assignments.
